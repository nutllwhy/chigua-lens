本说明用于区分“可以随公开仓库发布的项目资产”和“仅用于本地研究、不能因 MIT License 自动公开的第三方材料”。

## 公开发布包包含

- `docs/assets/demo-deck-montage.png`：由虚构“南风音乐节”案例的九页 PPT 渲染而成，只展示虚构人物、事件和信源。
- `docs/assets/chigua-deck-preview.png`：同一虚构案例的封面预览。
- `examples/demo/dossier.json` 与 `examples/demo/信源台账.md`：虚构数据，使用 `demo://` 标识演示信源。
- `examples/demo/吃瓜简报-南风音乐节.pptx`：由虚构数据生成的可编辑演示文件。
- `skills/chigua-deck/assets/chigua-cover.png`：项目使用的装饰性封面视觉，不作为真实现场、新闻图片或证据。
- 项目代码、项目自有文档与自有界面截图。

## 不纳入公开仓库

从公开网页取得的截图、现场视频或包含这些材料的二进制演示文件，只用于开发与人工核对，不因保存在本地目录中而获得重新分发授权。本项目将这类本地材料收纳在被 Git 忽略的 `tmp/private-case-assets/`；下面的路径规则同时防止它们被误放回真实案例目录后进入提交。

公开发布时排除以下文件类型：

```text
examples/侯明昊哽咽/*.png
examples/侯明昊哽咽/*.mp4
examples/侯明昊哽咽/*.pptx
examples/侯明昊哽咽/*.inspect.ndjson
```

真实案例若保留结构化文字档案，应同时保留原始网页 URL、发布者、发布时间、抓取时间和证据状态；不得把第三方图片或视频重新包装成项目自有素材。

## 新增素材检查

提交新的图片、视频、音频或字体前，请确认：

- 是否为项目贡献者自有、已获得授权，或许可明确允许再分发；
- 是否记录来源、作者、许可证和获取日期；
- 是否包含真实人物肖像、账号信息、私密聊天或敏感个人信息；
- AI 生成视觉是否只作为装饰，并且不会被误认为现场或证据；
- 移除该素材后，公开示例是否仍能独立复现。

如无法确认，默认不将二进制素材纳入公开仓库。
